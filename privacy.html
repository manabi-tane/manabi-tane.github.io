プライバシーポリシー

最終更新：2026年9月23日

まとめ

  • このサイトは個人情報を一切集めません。会員登録も、入力フォームも、問い合わせフォームもありません。
  • Cookie を使っていません。アクセス解析も広告も入れていません。
  • お気に入りや学習の記録はあなたの端末の中だけに保存され、こちらへは送られません。
  • 外部サービスの埋め込みはありません。書体も自前で配っています。

1. 運営者

日本在住の個人が、趣味で運営している無料の学習サイトです。企業・学校・出版社とは関係がありません。

連絡先：kokitezuka1@gmail.com

2. 集めていない情報

このサイトには、氏名・メールアドレス・電話番号・住所・生年月日・支払い情報などを入力する場所がありません。アカウントもありません。したがって、これらの情報を受け取ることも、保管することもありません。

3. 端末に保存されるもの

ブラウザの localStorage という仕組みを使って、次のものをあなたの端末に保存します。サーバーへは送信されません。

保存するもの内容目的
kobun:favoritesお気に入りに入れた章段の一覧次に開いたときも先頭に並べるため
kobun:learned:〈章段〉フラッシュカードで「覚えた」と仕分けした語続きから練習できるようにするため

消したいときは、ブラウザの設定からこのサイトのデータを削除してください。消しても学習内容そのものは変わりません（記録が初期状態に戻るだけです）。

4. アクセス解析・広告

Google Analytics などのアクセス解析は一切入れていません。広告も、アフィリエイトも、トラッキングピクセルもありません。何人が見たかも、誰が見たかも、こちらでは分かりません。

5. 外部サービス

ページを表示するときに、外部のサーバーへ接続することはありません。書体（Zen Old Mincho／Zen Kaku Gothic New）は Google Fonts から配信を受けるのをやめ、このサイト自身から配っています。訪問しただけで第三者にあなたの IP アドレスが渡ることはありません。

6. サーバーの記録

このサイトは GitHub Pages（GitHub, Inc.／米国）で公開しています。ページを取得する通信の性質上、GitHub 社のサーバーにはアクセス元の IP アドレスなどの通信記録が一定期間残ります。これは運営者が集めているものではなく、運営者は中身を見ることができません。GitHub 社の扱いについては GitHub プライバシーステートメント をご確認ください。

7. お子さまの利用

高校生の利用を想定していますが、個人情報を集めないため、年齢による制限は設けていません。保護者の方の同意が必要となるような情報の取得も行いません。

8. あなたの権利

個人情報を保有していないため、開示・訂正・削除のご請求に対してお渡しできるデータはありません。端末に保存された記録は、上記のとおりご自身でいつでも消せます。ご不明な点は連絡先までどうぞ。

9. 変更

内容を変えたときは、このページの最終更新日を改めます。大きな変更のときは、その旨をページ上部に書き添えます。
